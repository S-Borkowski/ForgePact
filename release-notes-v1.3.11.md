# ForgePact 1.3.11

Works together with Hero Siege Item Editor 2.15.3.

## Fixed

- **Some panel switches did nothing in the game.** In 1.3.9 and 1.3.10 the player
  build ignored Monster Rarity, Tyrant's Crown, Beacon and the Headhunter name labels:
  the panel showed them on, the game never received them. They work again.
- Nothing else changed. Density, drops, special content, enemy speed, Headhunter and the
  Tyrant's Crown / Headhunter drops are as in 1.3.10.

## How to update

Download the zip, unzip it, run ForgePact and press **Install** once. Start the game
after that; a game that was already open keeps the old plugin until it is restarted.

Use ForgePact only with an offline / EAC-disabled copy of Hero Siege.
