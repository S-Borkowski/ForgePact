# ForgePact 1.3.12

Works together with Hero Siege Item Editor 2.15.3.

## Changed

- **Tyrant's Crown and Headhunter now drop at the Angelic rate.** Every monster has a
  1 in 7500 chance, the same as an Angelic or Unholy item. There is no guarantee counter
  any more. The two items still take turns.
- Nothing else changed since 1.3.11.

## How to update

Download the zip, unzip it, run ForgePact and press **Install** once. Start the game
after that; a game that was already open keeps the old plugin until it is restarted.

Use ForgePact only with an offline / EAC-disabled copy of Hero Siege.
